## Context

`Equipment` 已有 equipped，但 UI 只對 weapon/armor 提供開關。能力值、技能與施法等欄位同時儲存基值／調整值；永久升級會改寫這些值，因此穿戴效果不能寫回它們。

## Goals / Non-Goals

**Goals:** 一般裝備可穿戴，玩家可設定簡單效果與同調條件，所有即時數值共用純函式推導。

**Non-Goals:** 解析敘述、魔法物品目錄、計時與充能、自動分配身體部位、完整效果條件語言。

## Decisions

- Equipment 新增可向後相容的 effects、requiresAttunement、attuned，以及可選 equippable（與 equipped 分開）。缺值時武器／護甲、已穿戴或有效果的一般裝備推定可裝備，其餘一般物品不可裝備；新物品明確保存旗標。編輯器僅管理可裝備，實際穿戴由清單控制，取消可裝備時卸下。效果採辨識聯集，限制數值範圍；消耗品不啟用穿戴效果，武器加值僅作用該武器。
- `equipment-effects.ts` 統一計算有效能力與衍生差額。原始角色始終傳給編輯、成長及儲存；顯示與即時規則讀取有效數值，避免把暫時效果混入永久成長。
- 同能力的下限取最高；能力加值先依各自上限作用於基礎值，再與下限取高，最高 30。不同物品加值相加，同名物品只取一份效果；數量不乘算。此為簡單效果範圍，特殊交互仍用敘述。
- HP 上限以有效體質差額 × 等級推導；裝備效果變更時調整目前 HP 同樣差額（0 HP 不因穿戴復活），維持已受傷量，且不超出有效上限。休息／治療以有效上限運作。
- 原生 select 強制 appearance-none、固定44px高度，配合自有箭頭，避免 Safari 使用較矮的系統選單外觀。
- 效果設定使用 client 元件（既有 EditorSheet），動態增刪列、明確標籤、至少 44px 控制項；沿用既有色彩 token，無 URL 狀態需求。
- 唯讀分享與列印使用相同純函式；顯示能力基礎值與來源，無寫入入口。
- 能力決定上限的既有職業資源（如吟遊激勵）隨有效修正更新，保留已花用差額；重載不回滿。
- 不強制檢查同調數量，保留職業例外與團務裁量；同調與穿戴分開，卸下不等於結束同調。

## Risks / Trade-offs

- [某處仍讀基礎值] → 搜尋所有即時能力與衍生讀取，測試屬性、攻擊、AC、施法、HP 與列印。
- [反覆穿脫／重載累積] → 推導不寫回基值；存檔／解析往返與升級回歸測試。
- [資料格式相容] → 新欄位使用預設值，既有物品不需 migration；不改靜態內容或資料表。

## Migration Plan

隨一般程式碼發布；角色 JSON 新欄位由 schema 預設填入，不需雲端操作。已完成本機驗證；2026-11-20 依使用者要求透過 OpenNext 與 Wrangler 部署並驗證正式站，紀錄見 docs/qa/equipment-stat-effects-2026-11-20/verification.md。
