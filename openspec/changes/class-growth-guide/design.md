## Context
角色卡目前只有已取得能力，不能預覽完整成長路線。使用者希望緊密、可掃讀的說明頁，也供功能核對使用。

## Goals / Non-Goals
Goals：12 職業的 1–20 級能力索引、選擇條件、替換規則、來源及選擇流程支援證據。
Non-Goals：不實作缺少的升級選擇，不改角色資料，不提供非 SRD 子職或複合職業規劃。

## Decisions
- 公開 Server Component 路由提供 metadata，client 元件負責篩選；靜態本地資料避免依賴登入或內容庫連線。
- 職業與模式反映 URL，搜尋為暫時狀態；返回瀏覽器歷史時保持職業。
- 既有 level-tables 是法術位、戲法數等進程的單一來源；新資料只補能力、決策摘要及 SRD 頁碼。
- 以等級為真正序列，窄左欄標級數，右欄先選擇再能力；不使用層層卡片。沿用 gold/text/token 色彩和 Cinzel 標題，compact/medium 單欄、expanded 側邊職業索引。
- 控制項至少 44px 並有 label；原生 details 展開完整選擇說明。預設隱藏支援狀態，核對模式才顯示支援範圍和程式證據。
- 支援標記只描述選擇操作，不代表所有戰鬥效果自動計算；附核對日期，未核對不標完成。

## Risks / Trade-offs
- 規則摘要漏掉限制 → 對照 SRD PDF、來源頁碼與核心決策測試。
- 狀態日後過期 → 獨立 coverage 資料與檔案證據，明示日期。
- 內容量大 → 職業切換、僅看選擇、搜尋；共同規則集中說明。
- 原工作區有大量修改 → 只改新增指南及入口，不覆寫既有工作。
