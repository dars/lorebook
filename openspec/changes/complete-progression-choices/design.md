## Context
指南列出所有 SRD 選擇，但角色 JSON 只有文字特性；升級未選法術，人類未選額外起源專長。

## Goals / Non-Goals
完整提供指南中的永久選擇、補選、升級及休息替換。保留既有角色與自創內容。
不匯入怪物數據、不支援多職、不以選擇表自動執行所有戰鬥條件效果。

## Decisions
- 用來源鍵、取得等級與選項快照保存 progressionChoices，避免解析翻譯過的特性名稱。欄位 optional，舊 JSON 不需 migration。
- 規則層產生具型別的選擇欄位與驗證，UI 共用緊密選擇器。新增、補選和替換用不同 context；不能藉補選重選已完成項目。
- 法術來源獨立；法術書與準備清單分開。新增來源不移除既有手動法術。
- 選擇帶動專精、熟練與職責加值；條件式戰鬥效果明確記錄，不能誤報已自動套用。
- 使用既有匿名 SRD 內容庫，靜態選項引用 SRD 頁碼；既有使用者保存沿用 RLS 與身分條件。

## Risks / Trade-offs
舊卡無來源不能可靠推測。補選先顯示舊內容供對照，使用者明確確認；不刪除手動內容。
選擇間可能有相依，須先驗證完整結果再原子套用；內容庫無法讀取時保留草稿與待補狀態，不造出成功結果。

## Migration Plan
新增 JSON optional 欄位，既有卡讀取保持原狀。部署前測試 schema 往返、規則與頁面。可回退 UI；新欄位留在 JSON。
