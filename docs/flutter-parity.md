# Flutter → Next.js 移植落差清單

**本次重跑**：2026-08-13（前一版 2026-08-08）
**方法**：Flutter `lib/**/presentation/**` 與 Next `app/`、`components/`、`lib/` 逐區對照，
再開**線上版**實際操作核對。上一版只做中文字串差集，誤判率偏高（見文末）。

**線上版的基準確認**：`https://lorebook.code4soul.dev` 目前仍是 Flutter build
（`flutter_bootstrap.js`）。抓下 `main.dart.js` 比對標記——無 `signInWithApple`、
有 `get_shared_character` / `user_backgrounds` / `toolProficiencies`——確認**線上 bundle
等於 git HEAD 的 `lib/`**，其後只有一筆「體能→運動」的中文改名（dart2js 編過後 grep 不到）。
因此拿 HEAD 的 Flutter 程式碼當基準是準的。

> **Next 端尚未部署過**：`wrangler deployments list` 回 `This Worker does not exist`。
> 目前只能拿本機 dev server（8087）對線上 Flutter。

**規模**：Flutter presentation 18,859 行 vs Next `app/`+`components/` 11,178 行
（8/8 時是 5,969）。Dart 比 TSX 冗長約 1.5–2×，**體量上已大致相當**，
剩下的落差是特定功能而非整體進度。

## 優先處理：會造成損害的錯誤 —— ✅ 七項均已修復（2026-08-13）

依「使用者會不會受損 × 症狀好不好聯想到成因」排序。以下保留原始描述作為判斷依據，
每項後方記修法。

1. **建角的法術資料被填空** — `components/creation/create-wizard.tsx:131-147`
   `description`/`range`/`damage` 硬寫成空字串、`castingTime` 一律寫死 `'1 action'`。

   全被標成動作，行動頁的附贈／反應分組全錯（火焰箭與護盾術都跑到動作區）。

   `spellFromCatalog`），`castKind` 由原始 `casting_time` 的 unit 推導，

2. **日誌未儲存確認框的按鈕寫「儲存」卻執行捨棄** —
   `components/journal/journal-view.tsx:167-183` ＋ `components/ui/editor-sheet.tsx:98-105`
   （`EditorSheet` 的主要按鈕標籤寫死「儲存」，而 `onSave` 掛的是丟棄）。
   內文只好補一句「按『儲存』捨棄變更」。使用者關掉寫一半的日誌、看到「儲存」按下去，

   受限於面板只有兩顆鈕，Flutter 的第三顆「儲存」暫未提供。

3. **升級離線跳過子職＝永久沒有子職** — Flutter 有 `?mode=subclass` 補選模式

   補選模式單看子職一段、按鈕改「完成補選」且**不可跳過**；子職特性取到角色
   **現有**等級（5 級才回來補的人一次補齊 1–5 級）。
   入口掛在角色卡而非 Flutter 的升級對話框裡——20 級角色的 LEVEL 徽章不可點，
   放那裡等於還是進不去。路由另有守衛：已有子職者訪問 `?mode=subclass` 導回角色頁，

### 建角的缺漏（上一版的逐項確認，保留作為判斷依據）

  ——兩者都仍全缺。新手不知道法師該把 +2 放智力。
- **購點成本表與那句解釋**——仍全缺。按 ＋ 到 14 時突然掉 2 點卻不知為何。

- **法術選取的詳情與計數**——Next 是純名稱 chip，連英文名都沒有，也沒有「已選 3/4」。
  使用者要在幾十個法術裡盲選。（分環選取本身已補上，舊結論那條已過期。）

  建完野蠻人，角色卡上沒有「狂暴」「無甲防禦」。
- **起源專長說明**：內建背景的 `originFeatDescription` 實測長度全為 0，
