# 成長選擇（SRD 5.2.1）

實作基準：職業成長指南；規則來源為 [官方 SRD 5.2.1](https://media.dndbeyond.com/compendium-images/srd/5.2/SRD_CC_v5.2.1.pdf)，不納入非 SRD 出版選項或怪物數據。

## 操作入口

- 建角：原法術步驟改為所有職業共用的「成長選擇」。
- 升級：依目標等級列出選擇與可替換項目。未完成的歷史選項可明確選擇稍後補齊。
- 角色頁：「成長選擇／補選」可補登舊角色，不提升等級。
- 完成短休／長休：行動頁與角色頁提供「休息後調整」。替換額度保存於角色；重新開頁不重置。
- 法師法術頁：法術書獨立管理；冒險抄錄由玩家與 DM 確認取得資格與費用。免費升級抄錄在成長選擇中管理。

已選選項維持原位，詳細效果可展開。一般法術與熟練管理面板不移除成長流程授予的項目。

## 覆蓋清單

| 類別 | 實作 |
|---|---|
| 共通 | 起始裝備／購裝金額、語言、能力值提升／專長、史詩恩賜、子職入口、各級法術名額 |
| 野蠻人 | 近戰武器精通、原初知識技能 |
| 吟遊詩人 | 樂器、專精、魔法奧祕的擴充清單、逸聞學院技能與魔法發現 |
| 牧師 | 神聖職責及額外戲法、祝福打擊、生命領域固定法術 |
| 德魯伊 | 原初職責及額外戲法、荒野形態名稱／CR／飛行限制、元素之怒、大地地形與法術 |
| 戰士 | 戰鬥風格、武器精通、勇士額外風格 |
| 武僧 | 工匠工具或樂器 |
| 聖騎士 | 戰鬥風格／祝福戰士、精通、固定法術與奉獻誓言法術 |
| 遊俠 | 戰鬥風格／德魯伊戰士、精通、語言、專精、獵人分支 |
| 盜賊 | 精通、專精、黑話及額外語言 |
| 術士 | 超魔、龍族元素親和及固定法術 |
| 邪術師 | 祈喚、等級／前置檢查、依戲法重複祈喚、魔書、先人教誨、祕法奧秘、邪魔韌性 |
| 法師 | 逐級法術書、已備法術、學者專精、塑能學者、法術精通、招牌法術 |
| 起源 | 人類額外起源專長、法術新手的清單／屬性／法術、熟練的技能／工具選擇 |

「已支援」指選擇、數量／資格檢查、保存與替換流程。戰鬥中的條件傷害、目標、召喚物、傷害抗性判定等仍由玩家依能力說明操作，不代表全面自動化。荒野形態僅記錄玩家確認的名稱與條件，沒有野獸資料庫。自創子職保留原本內容，不按相同名稱套用 SRD 子職規則。

## 資料與相容性

- `Character.progression`、`spellbook`、`progressionSource`、技能 `expertise`、法術 `castingSources` 均為相容舊 JSON 的新增欄位。使用既有 `user_characters.data`，無 migration、無 RLS 變更。
- 各來源有穩定鍵；一般已備法術、額外授予法術、法術書分開計數。同名法術合併顯示但保留各來源施法屬性與免費施法規則。
- 只重建本流程管理的紀錄；未選入名額的手動／自創資料保留。
- 舊角色起始裝備與歷史 ASI 可選「已經領取／已經套用」，避免重複套用。玩家仍需確認歷史分配；系統不猜測。
- 同一份選擇再次保存不增加裝備／金額／能力值，也不回復資源。進入成長頁前等待本機角色變更同步，避免休息與成長保存互相覆蓋。
- 角色卡與唯讀分享共用顯示元件；分享不提供編輯入口。

## 驗收紀錄（2026-10-29）

- 純規則回歸涵蓋 12 職業的 1–20 級來源、數量與取得等級，以及來源隔離、專精、替換額度、祈喚依賴、重複專長、形態條件、法術書、冪等性、舊卡相容。
- 本機使用公開內容庫（339 法術、210 物品、17 專長）跑過每職業 1→20 級的完整選擇套用，以及 25 套職業起始方案。未修改線上角色。
- 瀏覽器以暫時的開發驗收頁檢查實際 CreateWizard、LevelUpView、ProgressionView、CharacterSheet：人類法術新手、聖騎士替代戲法、戰士長休超額阻擋及合法替換、唯讀能力顯示。檢查 390px、768px 與桌面版面；驗收頁完成後移除。
- 登入後實際雲端寫入未使用使用者角色測試；保存沿用原 Server Action，新增欄位已做 JSON 往返及同步失敗／競態測試。

- 最終檢查：TypeScript、ESLint、794 項 Vitest 測試與 OpenNext Cloudflare 正式建置通過。部署版本以 Git commit 與線上 `/api/version` 為準。
