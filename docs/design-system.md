# Lorebook 視覺設計基礎

以已確認的首頁「夜藍 × 暖金 × Q 版角色插畫」為全站方向。實作的唯一色票來源為 `next/app/globals.css`；首頁不再覆寫自己的主題色。此次只統一設計基礎，維持既有頁面結構、功能、字級與緊密資訊排列。

## 配色

深色以夜藍作底、暖金標示操作與重點；淺色採灰綠白底與深黃銅重點色。角色插畫維持原色。不可把亮金文字直接放在淺色底上；實心主按鈕使用 `gold-solid` 搭配 `on-gold`。

| Token | 深色 | 淺色 | 最低對比（深 / 淺） |
| --- | --- | --- | --- |
| `text-primary` | `#f5ead5` | `#263d43` | 9.52 / 9.74 |
| `text-secondary` | `#bcc7cf` | `#526569` | 6.60 / 5.21 |
| `text-light` | `#c6cbd0` | `#526569` | 6.95 / 5.21 |
| `gold` | `#ebc77c` | `#735719` | 7.02 / 5.74 |
| `gold-dim` | `#cbb77e` | `#75602f` | 5.74 / 5.14 |
| `section-label` | `#d4be8d` | `#735719` | 6.24 / 5.74 |
| `danger` | `#f28e83` | `#b33326` | 4.85 / 5.22 |
| `success` | `#84c79b` | `#2a6e2d` | 5.74 / 5.30 |

對比以 WCAG 相對亮度公式計算，取 surface-0、surface-1、surface-2 三種背景中的最低值；一般文字門檻 4.5:1。傷害類型與臨時 HP 的文字亦已檢查三種背景。透明、停用和圖片上文字須按實際合成背景另行確認。

- `surface-0`：頁面底；深色 #19232d / 淺色 #f2f5f3。
- `surface-1`：內容卡片與編輯面板；深色 #24333f / 淺色 #ffffff。
- `surface-2`：次層內容；深色 #2c3c49 / 淺色 #e7eeeb。
- `border`：控制項輪廓；`border-2`：低強度分隔線，不單獨作為可操作狀態提示。
- `success`、`danger` 保留語意，不因插畫風改成裝飾色。

## 形狀與層級

- `radius-card` 12px：卡片、按鈕與一般表單欄位。
- `radius-chip` 8px：小標籤與緊密控制項。
- `radius-panel` 24px：登入區與彈出編輯面板。
- `radius-character-header` 20px：角色封面。
- `shadow-panel`：浮層、底部導覽；一般列表不用逐項加陰影。
- 編輯面板主要操作採暖金實心按鈕；取消為描邊；破壞性操作維持 danger。
- 盾牌、骰子、職業圖示與藥水等語意形狀維持原樣，不套用一般圓角。

## 字體與密度

沿用 Cinzel 品牌及重點數字、Source Sans 3 搭配系統中文內文、Inter 英文標籤。保留英中標題及細分隔線，不添加新字型下載。不為新視覺增加卡片內距或列表列高，觸控目標仍至少 44px。

## 維護

新增元件取用語意 token，不複製色碼；優先使用共用卡片與 EditorSheet。主題切換、初始 theme-color 與 PWA manifest 的背景色須同步。頁面專屬構圖與互動之後逐項微調，不在此階段改動角色規則、資料或編輯流程。

## 情境圖示與空白狀態

`AdventureIcon` 提供寶箱（收藏）、羽毛筆（旅程）、營火（休息）：32px viewBox、1.7px 圓頭描邊，少量金色半透明填色。圖示為裝飾，必須搭配文字，不單獨代替操作名稱。職業符號繼續使用既有 `ClassIcon` 圓頭描邊。

`AdventureEmpty` 使用既有翻書法師圖，96px 的橫向構圖搭配明確操作提示。空白提示只用於真正沒有內容的日誌和收藏。日誌與收藏頁另以 `adventure-backdrop` 常駐呈現背景法師，有資料時也保留；背景不接收點擊。收藏插畫限於標題右側專屬欄位（深色 70%、淺色 65%），不與文字重疊；日誌插畫深色 30%、淺色 18%，卡片使用 55% 表面底色讓完整輪廓可見，不增加列表高度。不加入循環動畫，不改戰鬥數值與資源控制。
